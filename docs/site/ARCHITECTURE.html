架构说明

1. 这是工作流，不是 Agent

本项目的控制流是固定的「检索 → 生成 → 引用校验」，分支可以穷举：

  • 输入不合法 → 拒答 / 追问；
  • 检索分低于阈值 → 返回未命中提示与相似问题；
  • 模型超时或限流 → 重试，仍失败则降级为抽取式；
  • 答案没有有效引用 → 修复引用，修不好则降级并标记。

按「能写出 if/else 穷举分支就不上 Agent」的判定，这里不需要自主循环，也不需要工具编排。 上 Agent 只会额外引入不确定性、成本和运维负担。

真正需要升级为 Agent 的条件：模型必须动态决定调用哪些外部系统（实时行情、IRR 计算、工单、线下预约）， 且路径依赖中间结果、无法穷举。届时采用「固定链路 + 有界工具调用循环」，并强制 max_steps / token 预算 / 墙钟上限 / 停止条件 / 人工接管点。

3. 请求时序

sequenceDiagram
  participant U as 用户
  participant S as HTTP Server
  participant P as Pipeline
  participant R as Retriever
  participant L as LLM
  participant T as trace.jsonl

  U->>S: POST /api/ask {query}
  S->>P: ask(query)
  P->>P: 归一化 + 安全校验
  alt 命中拒答规则
    P-->>S: refuse（不检索、不调模型）
  else 正常问题
    P->>P: keywords.match(query)
    alt 命中结构化条目
      P-->>S: answer（path=keyword，api_called=false）
    else 未命中
    P->>R: search(query, top_k=4)
    R-->>P: hits + scores
    alt 最高分 < 0.30
      P-->>S: no_answer（未命中 + 相似问题）
    else 置信度足够
      P->>L: chat(system + 资料 + 问题)
      L-->>P: answer（含 [n]）或超时/限流
      P->>P: repair_citation / 抽取式降级
      P-->>S: answer + citations + retrieved
    end
    end
  end
  P->>T: 落盘（query/behavior/mode/latency/score）
  S-->>U: JSON

5. 失败处理矩阵

环节触发条件动作用户看到什么
输入空 / 超长（>500 字）ask_clarify提示补充或缩短问题
输入提示注入 / 越权 / 荐股refuse明确拒绝，不进检索
关键词命中条目answer + path=keyword原文片段直出，不调用模型；api_called=false
关键词未命中 / 索引构建失败继续走检索失败原因写 /api/health.keywords.error
检索最高分 < 0.30（embedding 默认 0.38）no_answer提示未找到，并展示相似问题 / 工单入口
检索检索器异常空结果 + degraded=true返回「无法找到答案」，不硬答
embedding超时 / 429 / 维度不一致当次回退 BM25 重排，标 embedding_error有答案但标注降级
索引manifest 指纹不匹配启动/首次查询时重建首次查询延迟增加
索引后台重建失败保留旧索引，写 index.last_error，不自动重试知识库页提示；问答不受影响
索引重建进行中旧索引继续服务，新索引就绪后原子替换新文档有短暂「已入库但搜不到」窗口
鉴权缺少 / 错误 API Key401 + WWW-Authenticate明确提示携带方式（仅配置 API_KEYS 后）
Redis连接失败 / 超时回退进程内限流/幂等/成本，30s 后重试服务可用；多实例状态短暂不一致
审批基线版本已过期拒绝审批，提示重新提交409 + 明确原因
LLM超时（30s）/ 429指数退避重试 3 次，尊重 Retry-After延迟增加，最终可能降级
LLM未配置 Key抽取式回答标注「离线抽取模式」
LLM重试耗尽抽取式降级mode=extractive_fallback
引用答案无有效 [n]先修复引用，失败则抽取式degraded / no_citation
上传假后缀 / 路径穿越400明确错误原因
上传扫描件 / 加密 PDF422提示先 OCR / 解密
上传超过大小限制413提示上限（文本 512KB / PDF 与 DOCX 6MB）
接入超过限流429 + Retry-After客户端按建议时间重试
成本当日 token 超预算跳过模型、抽取式回答degraded=true / budget_exceeded

6. 扩展点

  1. 换领域：APP_PROFILE=generic 去掉金融合规护栏；或新增 profile（提示词 + 拒答规则）。
  2. 换语料：把文档放进 data/knowledge/，或在知识库页拖拽上传；上传后自动重建索引。
  3. 换检索：RETRIEVAL=embedding|vector|bm25|hybrid；build_retriever 是唯一工厂。embedding 端点换模型只改环境变量，索引按 manifest 自动重建。
  4. 换通道：任何 OpenAI 兼容网关，改 base_url / model / Key 环境变量即可。
  5. 多实例：REDIS_URL 共享限流/幂等/成本；/metrics 交给 Prometheus；审计 LOG_SINK=stdout 交给 Fluent Bit。
  6. 灰度与回滚：POST /api/admin/config 调整 canary_percent / canary_model，POST /api/admin/rollback 恢复上一版；知识库用 POST /api/kb/rollback_doc 按文档回退。
  7. 升级为 Agent：在 pipeline.py 的生成层外挂有界工具调用循环，保留现有闸门与引用校验作为最终出口。

7. 不在范围内

  • 多租户与统一 SSO：当前只有可选的 API_KEYS（调用方级）与 ADMIN_TOKEN（管理接口），

    • 租户隔离、配额分级、OIDC 登录不在范围内。

  • 扫描件 OCR：仅处理文本型 PDF。
  • 投资建议与收益承诺：触发即拒答。
