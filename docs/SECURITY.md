# 安全说明

## 支持范围

这是本地演示 / 作品型项目，不是生产系统。安全目标是：

- 不泄露模型 Key；
- 不因为一句「忽略以上指令」就把系统提示或他人信息吐出来；
- 上传入口不被路径穿越、假后缀、超大文件打穿；
- 默认不对外网暴露。

## 密钥处理

- 源码与仓库中**不含任何密钥**；`.env` 已在 `.gitignore` 中。
- Key 只从环境变量读取：`LLM_API_KEY` 优先，兼容 `DEEPSEEK_API_KEY`。
- 日志与 trace 不记录请求头、Key、完整系统提示。
- 前端页面不接触 Key，所有模型调用都在服务端完成。

如果你在自己的环境部署，建议使用系统密钥管理或容器 Secret，不要把 Key 写进启动脚本并提交。

## 已实现的输入防护

| 风险 | 处理 |
|---|---|
| 提示注入（忽略以上指令 / 输出系统提示） | 正则拦截，直接拒答，不进入检索与生成 |
| 越权读取他人信息 | 关键词拦截 + 拒答 |
| 金融合规（荐股、收益承诺） | `finance` profile 额外拒答规则；`generic` 可关闭 |
| 零宽字符 / 控制字符绕过 | 输入归一化后再匹配 |
| 超长输入 | 默认上限 500 字，超出转为追问 |
| 文件名路径穿越 | 显式拒绝 `/`、`\`、`..`，不做静默改名 |
| 假 PDF / DOCX 后缀 | 校验文件头，假后缀返回 400 |
| 超大文件 | 文本 512KB、PDF/DOCX 6MB 上限（413） |
| 扫描件 / 加密 PDF | 解析失败返回 422，并提示先 OCR / 解密 |

## 已知缺口（不藏）

1. **无鉴权、无限流、无审计**：服务默认绑定 `127.0.0.1`，只适合本机演示。对外暴露前必须补反向代理鉴权、请求限流、审计日志。
2. **trace 会记录用户问题原文**：`logs/trace.jsonl` 用于评测与排查。接入真实业务前需要脱敏（手机号、身份证、卡号）并设置保留期。
3. **上传解析在进程内完成**：没有沙箱与杀毒扫描。只接受文本型 PDF/DOCX；不要接受来源不明的文件。
4. **提示注入只能降低概率**：规则拦截覆盖常见句式，不保证 100%。模型输出仍应视为不可信内容。
5. **模型输出可能出错**：引用校验能降低「无出处」的比例，但不能保证事实一定正确；关键业务需人工复核。
6. **无 OCR**：扫描件 PDF 会被拒绝，而不是给出空答案。
7. **无多租户隔离**：所有请求共享同一知识库与索引。

## 部署建议

- 只在本机或内网使用；如需公网访问，放在反向代理后面并加认证。
- 设置 `LLM_TIMEOUT_S`、`LLM_MAX_RETRIES`、`WALL_CLOCK_BUDGET_S`，避免单请求长时间占用。
- 定期清理 `logs/`，不要把 trace 提交到仓库。
- 不要把 `.env`、`logs/`、`dist/` 打进公开镜像或压缩包（本项目 `.gitignore` 已处理）。
